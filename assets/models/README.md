# Models

Every model here is generated by `tools/assetgen` (run `python -m tools.assetgen` from the repo root).
The game loads them through `src/visual/model_slot.gd` and re-skins materials with the cel shader by material name,
so a replacement `.glb` only needs the same file name, node names and material names.

| Folder | Contents | Animated parts (node names) |
|---|---|---|
| `patient/` | `body.glb`, `site_heights.json` (skin heights per surgical site) | Torso, Head, Jaw, Eyes, Irises, Lids, UpperArm/Forearm/Hand L/R, Thigh/Shin/Foot L/R |
| `surgeon/` | `body`, `head`, `glove`, `upper_arm`, `forearm` | Torso, LegL/R; glove fingers Index/Middle/Ring/Pinky 1-3, Thumb |
| `tools/` | one per tool id or `model=` in tools.cfg | JawA/JawB, Plunger, Trigger, Blade, Flame, Glow, Light |
| `props/` | table, tray, IV stand, shelf, clipboard, stations, lamp, monitor, X-ray cart and print, straps, streetlight | X-ray `Arm` |
| `organs/` | bowel, lobe, sac (unit radius) | |
| `targets/` | bullet, knife, appendix, tumor, clot, figurine, bone, fragment, fluid, air | |

Special material names: `skin` (patient skin, carved open by the wound map), `tint` (recolored per instance),
`flame` (unshaded glow), `organ` (wet flesh shader).
Tools: grip at the origin, tip at `(0, 0, -length)` with `length` from `data/tools.cfg`.
